# Rayito — versión mejorada y adaptable

Web estática preparada para teléfono, tablet y computadora. No necesita
instalar dependencias ni incluye funciones de venta.

## Mejoras incluidas

- Diseño adaptable con controles táctiles y navegación por teclado.
- Cuatro temas visuales: Rayito, Neón, Fuego y Noche.
- Pantalla de carga con progreso y video de fondo optimizado.
- Reproductor de música, control de volumen y setup desplegable.
- Botones para compartir la página o copiar su enlace.
- Seis minijuegos con dificultad, pausa, reinicio, sonido y récords guardados
  en el navegador.
- Arena Survivor con disparo automático, oleadas, enemigos especiales, jefes,
  experiencia y mejoras elegibles en cada nivel.
- Penalty Master con arquero activo, marcador de tiros, goles y puntos.
- Cohete Espacial con velocidad progresiva según el tiempo sobrevivido.

## Probarla

Abrí `index.html` en el navegador. Para comprobarla como un sitio publicado,
también puedes servir la carpeta con cualquier servidor web estático.

## Controles de los juegos

- Mouse, pantalla táctil o `WASD`: Arena Survivor.
- Mouse o pantalla táctil: Pong, Rompeladrillos, Cohete y Penalty.
- Flechas del teclado o botones en pantalla: Snake.
- `P`: pausar o continuar.
- `R`: reiniciar el juego actual.
- `Esc`: volver al menú.

## Archivos principales

- `index.html`: contenido, reproductor y minijuegos.
- `style.css`: diseño adaptable para celular, tablet y computadora.
- `avatar.gif`, `favicon.png`, `fondo.mp4`, `poster.jpg` y `tu-cancion.mp3`:
  recursos visuales y de audio.

No requiere instalar dependencias.
