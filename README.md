# Rayito - versión adaptable

Esta carpeta contiene una web estática lista para abrir o publicar.

## Probarla

Abre `index.html` en el navegador. Para comprobarla como un sitio publicado,
también puedes servir la carpeta con cualquier servidor web estático.

## Archivos principales

- `index.html`: contenido, reproductor y minijuegos.
- `style.css`: diseño adaptable para celular, tablet y computadora.
- `avatar.jpg`, `favicon.png`, `fondo.mp4` y `tu-cancion.mp3`: recursos visuales
  y de audio.

No requiere instalar dependencias.
